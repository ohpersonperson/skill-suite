# Modes

## Operational modes

- **Standard (default depth: one-pass).** Narrative, relational, or bounded analytical fields. The five-phase one-pass run.
- **Systemic (deep run).** Large structural or technical systems. Deploy the 8-step meta-cycle below to map the field before running the nine-stage engine.
- **Stress-Test (session 2+).** Load the prior state artifact, evaluate incoming data, update Key dispositions (HELD / CRACKED / MODIFIED / SUPERSEDED / UNRESOLVED). Depth follows the field: one-pass for bounded updates, deep run for structural shifts.
- **Tribunal (deep run).** Adjudication: re-evaluate claims against FHK/Tribunal framework standards under adversarial collision. Full nine stages, no compression of the reasoning.

## 8-step meta-execution cycle

Wrap the nine-stage engine in this cycle when managing large, systemic, or ongoing multi-session fields:

1. **Gather the Field** — assemble incoming data, claims, contradictions.
2. **Map Relationships** — identify structural connections and dependencies.
3. **Locate Tensions & Harmonies** — surface hard contradictions and verified alignments.
4. **Extract Recurring Structures** — identify repeating patterns across contexts.
5. **Generate Explanatory Keys** — run the engine through Refine.
6. **Stress-Test Keys** — load prior state (session 2+) and test against new data.
7. **Update the Field** — reorganize the model based on surviving Keys.
8. **Iterate or Capture** — unresolved contradictions remain: loop **(this looping rule applies only here, on the deep/Systemic meta-cycle path — see loop-scope rule below)**. Otherwise emit the state artifact.

## Loop-scope rule

The no-loop and iterate-loop rules are scoped to their paths and do not contradict:

- **One-pass path (default): never loops.** Unresolved questions go in remainingUncertainties and primaryNextTarget — they do not trigger another pass. This is the engine's hard limit, inherited from IFS-PROTO v1.0.
- **Deep/Systemic path via the meta-cycle above: may iterate.** Step 8's "loop" applies only to large ongoing multi-session fields wrapped in this cycle. It never applies to the one-pass path.

## The nine stages (deep run)

IDENTIFY → DECOMPOSE → QUESTION → TEST → COLLIDE → REFINE → SURPRISE → SYNTHESIZE → CAPTURE STATE. Execute sequentially; do not skip or abbreviate.

- **QUESTION:** identify questions capable of materially changing the model. For each: what is unknown, why it matters, which interpretations it affects, what evidence would resolve it, what happens if YES / if NO. Unanswerable high-impact questions are preserved as unresolved dependencies, not dropped.
- **TEST:** attempt to break the strongest interpretations. For each: supporting evidence, contradictory evidence, unsupported assumptions, circular reasoning, alternative explanations, missing variables, predictions, falsifiers. Actively search for evidence that would make the interpretation wrong. Do not protect a favored explanation.
